# 🚌 Bus Booking System

A simple Bus Booking Web Application built using HTML, CSS, and JavaScript.  
This project allows users to search for buses, select seats, and confirm bookings through a clean and interactive UI.

---

## 🚀 Features

- Search bus by From, To, and Date  
- Interactive seat selection system  
- Real-time booking summary  
- Simple and responsive UI  
- Beginner-friendly frontend project  

---

## 📁 Project Structure

```
bus-booking-system/
│── index.html      # Main HTML file
│── style.css       # Styling file
│── script.js       # JavaScript functionality
```

---

## 🖥️ How to Run

1. Download or clone the repository  
2. Open the folder  
3. Double-click `index.html`  
4. Run it in your browser

---

## 🌐 GitHub Pages Deployment

1. Go to your GitHub repository  
2. Click **Settings**  
3. Open **Pages** section  
4. Select:
   - Branch: `main`
   - Folder: `/root`  
5. Click Save  
6. Your site will be live 🎉
